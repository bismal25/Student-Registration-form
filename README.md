## 📖 Overview

**Student Registration Form** is a front-end project that collects a student's personal details through a single, well-organised form. It was built to practise and showcase core HTML form elements: text inputs, radio buttons, checkboxes, dropdowns, text areas and file uploads.

The project has **no dependencies** and runs directly in any modern browser.

## ✨ Features

- 📝 Complete set of input types in one form
- 📧 Built-in browser support for email, number, date and phone inputs
- 🔘 Radio buttons for single-choice and checkboxes for multiple-choice answers
- 🌍 Country selection through a dropdown menu
- 🖼️ Profile picture upload
- 🔄 One-click **Reset** to clear the form
- ⚡ Lightweight: a single HTML file, no setup required

## 🧾 Form Fields

| Field | Input Type | Purpose |
|-------|-----------|---------|
| Full Name | `text` | Student's name |
| Email | `email` | Contact email (format checked by browser) |
| Password | `password` | Hidden characters for security |
| Contact | `tel` | Phone number (e.g. 03xxxxxxxxx) |
| Age | `number` | Numeric age |
| Date of Birth | `date` | Date picker |
| Gender | `radio` | Single choice |
| Hobbies | `checkbox` | Multiple choice |
| Country | `select` | Dropdown list |
| About Yourself | `textarea` | Short bio |
| Profile Picture | `file` | Image upload |

## 🚀 Getting Started

### Prerequisites

Any modern web browser (Chrome, Edge, Firefox, Safari). Git is optional.

### Run locally

```bash
# 1. Clone the repository
git clone https://github.com/bismal25/Student-Registration-form.git

# 2. Move into the project folder
cd Student-Registration-form

# 3. Open index.html in your browser
```

On Windows you can also just double-click `index.html`.

### Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
3. After a minute, your site will be live at:
   `https://bismal25.github.io/Student-Registration-form/`
